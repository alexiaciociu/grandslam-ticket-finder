# 🎾 Grand Slam Ticket & Travel Aggregator (Skyscanner for Tennis)

A web application designed to help tennis fans discover Grand Slam tournaments, compare options, and find tickets easily—inspired by Skyscanner's intuitive search experience.

## 🚀 About the Project
This project is a frontend web platform that aggregates major tennis Grand Slam tournaments (Australian Open, Roland Garros, Wimbledon, US Open). Users can search and filter tournaments based on:
* **Destination Country / Venue**
* **Date Range / Season**
* **Specific Tournament**

The goal is to provide a seamless, modern, and responsive user interface for tennis enthusiasts looking to plan their trips and secure tickets.

---

## 🛠️ Tech Stack
* **Markup & Styling:** HTML, CSS (Flexbox, Grid)
* **Logic / Interactivity:** JavaScript (DOM Manipulation, Event Handling, Filtering Logic)
* **Version Control:** Git & GitHub

---

## ✨ Key Features (Implemented & Planned)
- [x] Responsive landing page and tournament catalog layout.
- [x] Multi-criteria search and filter engine (by country, date, tournament).
- [ ] Ticket availability and price comparison view *(In Development)*.
- [ ] Interactive booking summary/modal *(Planned)*.
